# REC MVP Roadmap

## Phase 1 — Documentation and Planning
- Finalize PRD.
- Finalize TRD.
- Define software architecture.
- Define UI architecture.

## Phase 2 — Frontend Prototype
Build:
- Command center.
- Interactive map.
- Sensor panels.
- REC-SVLP panel.
- Incident system.

## Phase 3 — Simulation Engine
Create:
- Simulated drone route.
- Simulated telemetry.
- Sensor evidence events.
- State transitions.

## Phase 4 — Backend
Add:
- APIs.
- WebSocket updates.
- Incident persistence.
- Mission history.

## Phase 5 — Hardware Prototype
Integrate available hardware:
- Flight controller telemetry.
- GPS.
- Thermal sensing.
- Microphone sensing.
- Visual data.

## Phase 6 — Physical Demonstration
Demonstrate:
Search → Suspicion → Investigation → Verification → Alert

## Recommended Immediate Priority
Build the frontend with simulated data first. This reduces hardware dependency and allows the project concept to become demonstrable early.
